PART A: SIMPLE FUNDAMENTAL EXAMINATION QUESTIONS

QUESTION S1: Expressions & Data Binding in AngularJS

Programs 34 & 36

Aim: To demonstrate numeric, string, boolean, object, and array expressions in AngularJS and compare one-way vs two-way data binding.

Algorithm: 1) Create module and controller; 2) Define variables in $scope; 3) Interpolate expressions via {{ }}; 4) Bind input with ng-model for bidirectional updates.

<p>Numeric: {{ 15 * 4 + 10 }} | String: {{ 'Hello ' + 'AngularJS' }} | Boolean: {{ 25 > 10 }}</p> <input type="text" ng-model="liveText"> <p>Two-Way Live Value: {{ liveText }}</p>

Output: Expressions compute and render directly; modifying the input updates the bound paragraph simultaneously.

QUESTION S2: ng-model Directive Classes & Validation States

Program 35

Aim: To illustrate form validation states and CSS classes added by ng-model ($valid, $invalid, $pristine, $dirty, $touched, $untouched).

Algorithm: 1) Construct HTML form with required email field; 2) Add CSS classes for .ng-valid (green) and .ng-invalid.ng-touched (red); 3) Display live property flags.

<form name="userForm"> <input type="email" name="userEmail" ng-model="email" required> <span>Valid: {{ userForm.userEmail.$valid }} | Dirty: {{ userForm.userEmail.$dirty }}</span> </form>

Output: Border color transitions between green and red dynamically as valid email characters are typed or cleared.

QUESTION S3: Built-in & Custom Filters in AngularJS

Program 38

Aim: To demonstrate 10 built-in filters (uppercase, lowercase, currency, number, limitTo, orderBy, filter, json, date) and define a custom filter.

app.filter('reverse', function() { return function(input) { return input ? input.split('').reverse().join('') : ''; }; }); // View usage: {{ amount | currency:"₹ " }} | {{ name | uppercase }} | {{ text | reverse }}

Output: All data items are transformed and displayed according to their respective filter pipes.

QUESTION S4: Directives: ng-repeat Table & Conditional Views

Programs 401, 41, 44

Aim: To render collections in tables using ng-repeat ($index, $even, $odd) and compare ng-if, ng-show/hide, and ng-switch.

<tr ng-repeat="s in students track by $index" ng-class="{'row-even': $even, 'row-odd': $odd}"> <td>{{ $index + 1 }}</td><td>{{ s.name }}</td> <td ng-switch="s.status"><span ng-switch-when="Active" class="badge">Active</span></td> </tr>

Output: Student records render in alternating table rows with badges controlled via ng-switch.

QUESTION S5: AngularJS $http Asynchronous Services

Programs 39 & 402

Aim: To execute AJAX requests using $http.get(), $http.post(), $http.put(), and $http.delete() and display the JSON responses.

$http.get('https://jsonplaceholder.typicode.com/posts/1').then(function(res) { $scope.responseData = res.data; });

Output: Button clicks trigger network requests and display parsed JSON formatted on screen.

QUESTION S6: Node.js CLI Arguments, Local Modules & Core Modules

Programs 59 to 62

Aim: To parse command-line arguments (process.argv), require a local math module, and query host system specs using os, path, and util.

const os = require('os'); const math = require('./utils_math'); console.log('CLI Args:', process.argv); console.log('Math Add:', math.add(10, 20)); console.log('OS Platform:', os.platform(), 'CPUs:', os.cpus().length);

Output: Console prints argument indices, math calculations, and OS hardware telemetry.

QUESTION S7: Node.js HTTP Server Routing & File System (fs) CRUD

Programs 63 to 66

Aim: To create an HTTP server with clean routing and execute synchronous/asynchronous file CRUD operations.

fs.writeFileSync('test.txt', 'Hello'); fs.appendFileSync('test.txt', ' Node.js'); fs.readFile('test.txt', 'utf8', (err, data) => console.log(data)); http.createServer((req, res) => { if (req.url === '/') res.end('Home'); else res.end('404'); }).listen(3002);

Output: File lifecycle completes in terminal; HTTP server listens on port 3002.

QUESTION S8: Node.js URL Parsing & Event Handling (EventEmitter)

Programs 67, 68, 70, 73

Aim: To parse URL parameters using the url module and implement an event observer via EventEmitter.

const url = require('url'); const EventEmitter = require('events'); const emitter = new EventEmitter(); emitter.on('visit', (path) => console.log('Visited:', path)); http.createServer((req, res) => { emitter.emit('visit', url.parse(req.url, true).pathname); res.end('Logged'); }).listen(3003);

Output: Page requests fire custom events and log visitor hits in real time.
