📜 Value Access using STATEMENTS

Using Dot Notation, Bracket Notation, Array Indexing, and Destructuring:

// Sample Object: student
student.name                 // Dot notation
student["email"]             // Bracket notation
student.address.city         // Nested property
student.skills[0]            // Array element
const { name, course } = student; // Destructuring

🔁 Value Access using LOOPING

Iterating through JSON objects and arrays using 5 loop types:

for (key in student) { ... }      // for...in (keys)
for (item of studentsList) { ... } // for...of (array)
studentsList.forEach(s => ... )   // forEach
studentsList.map(s => s.name)     // map transformation
studentsList.filter(s => ...)     // filter query
