To see the output:
1) Keep `data.xml` and `display.html` in the same folder (already done).
2) Open `display.html` in a browser.

Note: Some browsers block XMLHttpRequest from local files (file://). If the table stays empty, run a simple local server and open http://localhost:
- Python:  (cd c:/vijay/17)  python -m http.server 8000
- Then open: http://localhost:8000/display.html
