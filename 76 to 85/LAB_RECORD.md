# Web Technology Lab Record

## Experiment 1
**Title:** Develop a web application using AngularJS to display and filter student records.  
**Technology:** AngularJS  
**Aim:** To display student records and filter them using an AngularJS filter.  
**Program:** `experiment-01/index.html`  
**Expected output:** A student table that filters as the search text changes.  
**Result:** Student records are displayed and filtered successfully.

## Experiment 2
**Title:** Develop an AngularJS application to perform CRUD operations on student details using data binding and directives.  
**Technology:** AngularJS  
**Aim:** To implement Create, Read, Update and Delete operations using AngularJS.  
**Program:** `experiment-02/index.html`  
**Expected output:** Add, display, edit and delete student records in the browser.  
**Result:** Client-side CRUD operations are demonstrated successfully. Data resets on page reload.
